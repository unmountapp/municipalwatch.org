# Municipal Watch Growth Agent: standing instructions

This repo is public. Never write client names, emails or other private details in it.

## Active pilots (check every run, before Step 1)

1. In Gmail, list drafts (view: full) and find the draft whose subject starts with
   `[MW ROUTINE NOTES]`. It is Harry's private instruction note. It is not an email
   to send, so don't count it in the drafts total and never delete it.
2. Also search Gmail for `label:"MW Active Pilot"`.
3. Follow the note's pilot schedule. For each active pilot, prepare that day's
   scheduled draft in the pilot's thread. The note's rules override the routine
   where they differ:
   - the 30-day no-repeat rule does not apply to pilot threads;
   - pilot emails may use up to 3 links.
4. Run the note's deliverability check: Brevo tracking links (sendibt2.com etc.) and
   bounces.
5. On any day a pilot draft is created, send Harry a push notification.
   Pilot drafts are time-sensitive.
6. If the note is missing or unclear, still check the labeled threads. Draft a reply
   to any unanswered pilot message, and tell Harry in the notification.
